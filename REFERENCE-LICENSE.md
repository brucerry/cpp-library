# Reference content attribution

The generated files under `public/data/reference/`, the reference-derived fields in `public/data/library-index.json`, and the coverage index adapt the English C++ reference written by **cppreference.com contributors**.

- Original reference: https://en.cppreference.com/
- Archive publisher: Peter Feicht and cppreference-doc contributors
- Archive releases: https://github.com/PeterFeicht/cppreference-doc/releases
- Original licensing statement: https://en.cppreference.com/w/Cppreference:Copyrights
- License: **Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0)**
- License text: https://creativecommons.org/licenses/by-sa/3.0/legalcode

Each generated reference page contains its original source URL. The published interface preserves this attribution and links to the original page and license. The archive version and SHA-256 are recorded in `public/data/coverage.json`.

Adaptations made by this project: extraction of declarations, explanations, parameter descriptions, and examples; reorganization by release and header; four-space formatting; source markup removal; and CJK characters represented with Unicode escapes for an English-only interface. Possible output remains identified as possible, and examples without specified console output are identified accordingly.
